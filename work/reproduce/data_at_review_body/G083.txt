## Summary

This PR implements automatic suppression of the CS8002 warning (referenced assembly doesn't have a strong name) for projects targeting .NET Core (.NETCoreApp) and .NET Standard TFMs. 

### Changes Made:
1. **Modified `Microsoft.NET.Sdk.CSharp.targets`** - Added a PropertyGroup that appends CS8002 to the NoWarn list when `_IsNETCoreOrNETStandard` is true
2. **Added comprehensive tests** in `GivenThatWeWantToSuppressCS8002Warning.cs` to verify:
   - CS8002 is suppressed for net6.0, net7.0, net8.0, netstandard2.0, and netstandard2.1
   - CS8002 is NOT suppressed for net472 and net48
   - CS8002 suppression works correctly with existing NoWarn values

### Verification:
- All 8 tests pass successfully
- Manual verification confirms CS8002 is in NoWarn for .NET Core/Standard projects (e.g., "1701;1702;CS8002")
- Manual verification confirms CS8002 is NOT in NoWarn for .NET Framework projects (e.g., "1701;1702")

This resolves the issue by automatically suppressing the CS8002 warning which is irrelevant on modern .NET runtimes where strong name validation is not enforced.
