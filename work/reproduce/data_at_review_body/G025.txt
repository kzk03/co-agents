## Overview

This PR renames the `md` report to `markdown` throughout the detekt codebase, following the same principle as #8471 where report names should reflect the format rather than just the file extension.

## Changes

### Module and Package Rename
- Renamed module from `detekt-report-md` to `detekt-report-markdown`
- Updated package from `dev.detekt.report.md` to `dev.detekt.report.markdown`
- Updated all project accessor references from `projects.detektReportMd` to `projects.detektReportMarkdown`

### API Changes
- Added `reportId = "markdown"` to `MdOutputReport` class (the class name remains unchanged for minimal API breakage)
- Renamed `DetektReportType.MD` enum to `MARKDOWN` with `reportId = "markdown"` and `extension = "md"`
- Updated `DetektReports` Gradle DSL from `reports.md` to `reports.markdown`

### What Stays the Same
- Class name: `MdOutputReport` (to minimize breaking changes)
- File extension: `.md` (controlled by the `ending` property)
- Internal report ID: `"MdOutputReport"`

## Usage Changes

Users will need to update their configurations:

**Gradle DSL:**
```kotlin
// Before
reports {
    md.required.set(true)
    md.outputLocation.set(file("build/reports/detekt.md"))
}

// After
reports {
    markdown.required.set(true)
    markdown.outputLocation.set(file("build/reports/detekt.md"))
}
```

**CLI:**
```bash
# Before
detekt --report md:build/reports/detekt.md

# After
detekt --report markdown:build/reports/detekt.md
```

Note that the file extension remains `.md`, so output file paths don't need to change.
