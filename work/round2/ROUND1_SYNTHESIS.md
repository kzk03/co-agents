## 2. 理論(theory)
- 中核理論: 不完備契約の残余コントロール権 + Aghion & Tirole の形式的/実質的権限。補助: Suchman(状況に埋め込まれた行為)、
  Collins の暗黙知3分類、meaningful human control(tracking/tracing)、responsibility gap / moral crumple zone、Bainbridge。
- 能力の判断(正解あり、内容で効く: C/K/R-tech)と正統性の判断(正解なし、発言者で効く: D/R-gov)を分ける。テスト T1〜T4:
  T1 効力の非対称(AI と人間で同じ D 指摘の採用率)、T2 権限による分布差(core vs 非 core の -1)、T3 人間同士でも割れるか、T4 結論の一致。
- 新しい事実: pilot で copilot-pull-request-reviewer COMMENTED 55,726 / CHANGES_REQUESTED 0、gemini-code-assist 3,212 / 0。
  (Copilot が仕様上 CR を出せないかは未確認)
- 中心命題候補: P1 残余決定権、P2 文書弾力性の非対称、P3 形式/実質権限の乖離。

## 3. 方法論(method)
- 生き残り(記述として): Gerrit > AIDev の H 比率(盲検差 +0.185)、-2 はほぼ H(14/15)、closed ほど H、Copilot CR は指示に近い(依頼者=レビュアー 79.6%)。
- 死亡: 作者で理由が違う(ただし「同等」の主張には1群412件必要)、委任仮説、主観 inferable。
- 未決: リーク除去後の H<C(n 不足)、K/R/D 別再現率、スケール効果(未測定)。
- 脅威: リーク 12/30(H に偏る)、学習データ汚染、最大10件で数打ち、同社判定者、Copilot 偏重、選択バイアス。
- 提案: 再現 v2 = 情報のはしご L0〜L4(L4 は人間が欠けていた前提を書く)× モデル3〜4世代、K/R/D/C 各 60〜80。
  本番は claude -p 約2,300〜7,900 回で現上限(100)を超える → パイロット 96 回。人間校正 2名 170件、レビュアー固定効果、AGENTS.md 追加の DiD。
- 「スケールに殺されない」の操作的定義: L4 でも再現されず世代の傾きが C より小さい = 認識上の残差、
  人間同士でも割れる D・規則が人間承認を要求するもの = 権限上の残差。

## 私(メイン)の暫定判断
- 「AI に再現できない判断」(能力)を主張の中心に置くのはやめる。SWE-PRBench 等に先を越され、データも支持しない。
- 中心は「人間に残るのは権限・正統性で効く判断で、それは作者ではなくレビュアー側・repo の統治構造の属性」(P1)に寄せ、
  P2(文書を増やしても D は減らない)を反証可能な主仮説として DiD で検証、能力側は再現 v2 で「残差がどう縮むか」を副次的に測る。
- ラウンド2: レッドチームで P1/P2 を潰しにかかる、分析 A(Gerrit の T2/T3/集中/所有度、レビュアー固定効果の実現可能性)、
  分析 B(文書による被覆と書き足し、CR 後の経過分類)。
